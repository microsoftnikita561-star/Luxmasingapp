# LuxMasing — тренажёр луксмаксинга

Веб-приложение (работает на телефоне и ПК), которое шаг за шагом делает человека лучшей версией себя — только безопасными, доказательными методами.

## Возможности

- **Анализ лица** — [MediaPipe Face Landmarker](https://ai.google.dev/edge/mediapipe/solutions/vision/face_landmarker) находит 478 точек лица на устройстве. 14 пропорций (симметрия, кантальный наклон, FWHR, средняя зона, трети лица, челюсть/скулы и др.), форма лица, подбор стрижки, бороды и очков, приоритеты.
- **Кожа** — детектор воспалений: маска кожи по точкам лица, поиск покраснений в цветовом пространстве CIELAB, подсчёт по зонам, степень. Схема ухода и конкретные аптечные средства под степень и возраст (по AAD 2024, NICE NG198, инструкциям препаратов). По желанию — второе мнение от ИИ через OpenRouter.
- **Программа** — ежедневные задачи под пол, возраст, акне; XP, 9 уровней, серии.
- **Тренировки** — мимика с камерой (52 мышечных показателя в реальном времени: squinch, улыбка Дюшенна, расслабленный лоб, ракурс) и три комплекса для осанки, шеи и тела с реальными фото начала и конца каждого движения (база [free-exercise-db](https://github.com/yuhonas/free-exercise-db), общественное достояние) и видео техники с YouTube.
- **Академия** — базовые и углублённые уроки с тестами, словарь терминов.
- **Прогресс** — история фото, графики, сравнение замеров, вес/талия/сон, динамика воспалений.
- **Коуч** — чат через [OpenRouter](https://openrouter.ai), видит профиль и замеры, разбирает фото.
- **Битва** — сравнение двух фото по семи раундам (симметрия, глаза, челюсть, пропорции, кожа), «я против себя в прошлом» по сохранённым замерам и битва с другом по ссылке на профиль. Раунд не засчитывается, если фото искажает измерение; разница в пределах погрешности — ничья.
- **Честные замеры** — метрики, искажённые улыбкой, поднятыми бровями или поворотом головы, исключаются из итога; показывается точность замера.
- **Фокус** — на главной три приоритета, посчитанные из замеров кожи, лица и реально пропускаемых привычек.
- **Поделиться профилем** — картинка-карточка и ссылка; фото лица в них не попадает.

Ключ OpenRouter вводится в профиле и хранится только в браузере пользователя. Не добавляйте ключ в код: репозиторий и собранный сайт публичны.

## Почему MediaPipe, а не LLM для точек лица

LLM (через OpenRouter) не умеют точно ставить точки на лице — они «угадывают». Для геометрии нужна специализированная модель: MediaPipe Face Landmarker даёт точные 478 точек, бесплатна, работает офлайн и быстро даже на телефоне. LLM используется там, где он силён: разбор кожи, волос, стиля и персональные планы.

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # сборка в dist/
```

Камера в браузере работает только по `https://` или на `localhost`.

## Деплой

Workflow `.github/workflows/deploy.yml` публикует сайт на GitHub Pages при пуше в `main`. Включите: Settings → Pages → Source: **GitHub Actions**.

## Дисклеймер

Приложение образовательное и не является медицинским изделием. Геометрия на 2D-фото — не «оценка красоты». По лекарствам и процедурам — только к врачу.
