# LuxMasing — тренажёр луксмаксинга

Веб-приложение (работает на телефоне и ПК), которое шаг за шагом делает человека лучшей версией себя — только безопасными, доказательными методами.

## Возможности

- **🔬 ИИ-анализ лица** — нейросеть [MediaPipe Face Landmarker](https://ai.google.dev/edge/mediapipe/solutions/vision/face_landmarker) находит 478 3D-точек лица **прямо на устройстве** (фото никуда не отправляются). Считает 14 пропорций: симметрия, кантальный наклон, FWHR, midface ratio, ESR, трети лица, подбородок/фильтрум, челюсть/скулы, нос, рот, правило пятых, раскрытие глаз, губы, брови. Определяет форму лица и подбирает стрижку, бороду и очки. Для каждой метрики — что она значит, насколько её реально изменить и как.
- **✅ Ежедневная программа** — ~30 задач (кожа, тело, осанка, волосы, сон, стиль, подача), персонализированных под пол, акне, бороду; XP, 9 уровней (до «Луксмастер» и «Легенда»), серии, тепловая карта.
- **🎯 Тренажёр мимики** — камера + 52 мимических коэффициента в реальном времени: squinch («hunter eyes»), улыбка Дюшенна, расслабленный лоб, симметричная полуулыбка, фотогеничный ракурс. Подсказки в реальном времени, удержание и повторы.
- **🎓 Академия** — 21 урок в 6 модулях с тестами: кожа (SPF, ретиноиды, акне), процент жира, тренировки, осанка, мьюинг (правда и мифы), зубы, стрижки, выпадение волос, брови, борода, сон, стиль, фотогеничность, харизма, опасные методы и hardmaxxing.
- **📈 Прогресс** — история фото, графики гармонии/симметрии, сравнение двух замеров по каждой метрике, вес/талия/сон.
- **🤖 ИИ-коуч** — чат через [OpenRouter](https://openrouter.ai) (Gemini, Claude, GPT и др.), видит профиль и результаты анализа, разбирает фото кожи/волос/стрижки. Ключ хранится только в браузере.

## Почему MediaPipe, а не LLM для точек лица

LLM (через OpenRouter) не умеют точно ставить точки на лице — они «угадывают». Для геометрии нужна специализированная модель: MediaPipe Face Landmarker даёт точные 478 точек, бесплатна, работает офлайн и быстро даже на телефоне. LLM используется там, где он силён: разбор кожи, волос, стиля и персональные планы.

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # сборка в dist/
```

Камера в браузере работает только по `https://` или на `localhost`.

## Деплой

Workflow `.github/workflows/deploy.yml` публикует сайт на GitHub Pages при пуше в `main`. Включите: Settings → Pages → Source: **GitHub Actions**.

## Дисклеймер

Приложение образовательное и не является медицинским изделием. Геометрия на 2D-фото — не «оценка красоты». По лекарствам и процедурам — только к врачу.
