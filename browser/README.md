# LuxBrowser

Лёгкий приватный браузер на движке Chromium (через Electron). Сайты открываются так же, как в Chrome, но без слежки и с экономией памяти.

## Как скачать готовый браузер

1. Откройте вкладку **Actions** в репозитории → **Build LuxBrowser** → последний зелёный запуск.
2. Внизу, в **Artifacts**, скачайте `LuxBrowser-Windows` (или Linux / macOS).
3. Windows: `LuxBrowser Setup 1.0.0.exe` — установщик, `LuxBrowser 1.0.0.exe` — портативная версия без установки.
   Windows может предупредить «неизвестный издатель» (программа не подписана платным сертификатом) — «Подробнее» → «Выполнить в любом случае».

## Как запустить из исходников

```bash
cd browser
npm install
npm start
```

Собрать установщик у себя: `npm run dist:win` (или `dist:linux`, `dist:mac`), результат в `browser/dist/`.

## Перенос данных из Google Chrome

При первом запуске браузер сам находит Chrome и предлагает перенести данные одной кнопкой (позже — меню ⋮ → «Перенести закладки и историю из Chrome…»). Chrome закрывать не нужно, перенос занимает пару секунд.

- Переносятся: все закладки с папками (панель закладок выглядит как в Chrome) и история — по ней сразу работают подсказки в адресной строке и плитки часто посещаемых сайтов.
- Поддерживаются также Яндекс Браузер, Edge и Brave, и несколько профилей.
- Не переносятся пароли и входы на сайты: Chrome шифрует их с привязкой к себе, другая программа прочитать их не может. На сайты нужно будет войти заново.

## Интерфейс как в Chrome

Вкладки сверху, круглая адресная строка с подсказками, звёздочка закладок, панель закладок с папками, меню ⋮, страница новой вкладки с поиском и часто посещаемыми сайтами, страница истории (Ctrl+H), поиск по странице (Ctrl+F). Светлая и тёмная темы — по теме системы. Горячие клавиши те же, что в Chrome, и работают при русской раскладке.

## Что он делает

**Меньше памяти**
- Фоновые вкладки «засыпают» через 10 минут (настраивается): страница выгружается из памяти, а адрес, история «назад/вперёд» и заголовок сохраняются. Клик — и вкладка просыпается. Вкладки, где играет звук, не усыпляются.
- Вкладки, восстановленные после перезапуска, не загружаются, пока вы их не откроете — браузер стартует быстро.
- Отключены: запасной «пустой» процесс про запас, проверка орфографии (качает словари), фоновые сетевые службы, обновления компонентов, Privacy Sandbox / Topics.
- Режим экономии: максимум 4 процесса для страниц (меньше памяти, но слабее изоляция сайтов друг от друга).
- В меню видно, сколько памяти занято всеми процессами браузера.

**Не следит**
- Никакой телеметрии, аккаунтов и синхронизации: история и закладки лежат только в файлах на вашем компьютере.
- Встроенный блокировщик рекламы и трекеров (списки EasyList/EasyPrivacy через движок Ghostery). Счётчик на щите показывает, сколько отбито на странице.
- **Блокировщик скрыт от сайтов** (галочка «Скрывать блокировщик от сайтов»):
  - заблокированные рекламные скрипты и картинки для сайта выглядят как успешно загруженные (вместо ошибки сайт получает пустой файл или заглушку вроде фальшивого объекта Google Analytics);
  - «приманки» — пустые блоки с рекламными именами, по которым сайты проверяют, скрыта ли реклама, — отвечают, будто они видны;
  - списки фильтров включают правила против «отключите блокировщик» (uBlock Origin, Adblock Warning Removal List, RU AdList) и обновляются раз в 3 дня;
  - если какой-то сайт всё равно заметил блокировщик: меню ⋮ → «Не блокировать на этом сайте».
- Куки не отправляются сторонним сайтам (рекламные сети не узнают вас на разных сайтах).
- Из ссылок вырезаются метки слежки: `utm_*`, `fbclid`, `gclid`, `yclid`, `ysclid` и др.
- Заголовки «Не отслеживать» (DNT) и Global Privacy Control.
- WebRTC не выдаёт ваш локальный IP-адрес.
- Строка браузера (User-Agent) выглядит как обычный Chrome — меньше уникальных признаков.
- Защищённый DNS (DNS-over-HTTPS): Cloudflare, Quad9 или AdGuard — провайдер не видит, какие сайты вы открываете.
- Камера, микрофон, геолокация, уведомления — только после вашего «Разрешить».
- По желанию: стирать куки, кэш и историю при каждом выходе.
- Поиск по умолчанию — DuckDuckGo (можно Brave, Startpage, Google, Яндекс).

**Быстрее грузит страницы**
- Реклама и трекеры даже не скачиваются — на тяжёлых новостных сайтах запросов становится заметно меньше.
- Пока вы печатаете адрес, браузер заранее открывает соединение с самым вероятным сайтом.
- Наводите мышь на ссылку или закладку — соединение с её сервером открывается заранее, и клик срабатывает быстрее.
- Включены QUIC/HTTP3 и кэш «назад/вперёд».
- Быстрый запуск: окно показывается сразу, вкладки прошлого сеанса не грузятся, пока вы на них не нажмёте, блокировщик поднимается из готового кэша.

## Горячие клавиши

| Клавиши | Действие |
|---|---|
| Ctrl+T / Ctrl+W | новая / закрыть вкладку |
| Ctrl+Shift+T | вернуть закрытую вкладку |
| Ctrl+L, F6 | в адресную строку |
| Ctrl+Tab, Ctrl+1…9 | переключение вкладок |
| Alt+← / Alt+→ | назад / вперёд |
| F5, Ctrl+R (Shift — без кэша) | обновить |
| Ctrl+D | закладка |
| Ctrl+Shift+B | показать / скрыть панель закладок |
| Ctrl+H | история |
| Ctrl+F | найти на странице |
| Ctrl + / − / 0 | масштаб |
| F11 | полный экран |
| F12 | инструменты разработчика |

## Честно об ограничениях

- Это оболочка над Chromium (Electron), а не собственная сборка Chromium: расширения Chrome Web Store не поддерживаются, а обновления движка приходят с новыми версиями Electron (`npm update electron` и пересборка).
- «Быстрее любого браузера» гарантировать нельзя: на сайтах без рекламы скорость будет как у Chrome — движок тот же. Выигрыш заметен на сайтах с рекламой и трекерами.
- Один процесс-оболочка весит примерно столько же, сколько у Chrome; основная экономия — от сна вкладок и блокировки рекламы.
- Скрытие блокировщика не всесильно: сайты постоянно придумывают новые проверки, и отдельные (например, YouTube) могут его заметить — тогда помогает выключатель для сайта.
- Сторонние куки блокируются на исходящих запросах, поэтому встроенные чужие виджеты (комментарии Disqus, «войти через…» во фрейме) могут не видеть ваш вход — галочку можно снять в меню.
