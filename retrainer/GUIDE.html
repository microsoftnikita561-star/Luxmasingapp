Инструменты реверсера

Минимальный набор под Windows x64.

Статический анализ

  • IDA Free/Pro — дизассемблер + декомпилятор (F5)
  • Strings в IDA: Shift+F12
  • Ghidra — бесплатная альтернатива
  • strings.exe / PE-bear — быстрый осмотр

Динамический анализ

  • x64dbg — отладчик, брейк на сравнение
  • ScyllaHide — против анти-отладки (ур. 4, 5)
  • HxD — hex-правки на диске
  • Запускай мишени в ВМ по привычке

поток: strings → найти интересное → xref к проверке → понять логику в декомпиляторе → решить (ввести ключ / кейген / патч перехода).

1

QuickReels Proновичок

Ключ лежит открытым текстом и сравнивается напрямую.

Чему учит

  • Поиск строк и xref
  • Чтение секции .rdata
  • Базовый статический анализ

Как подойти

  1. Открой ch1_quickreels.exe в IDA
  2. Shift+F12 → ищи строку-лицензию
  3. Двойной клик → x → к сравнению
  4. Ключ прямо там. Введи его.

инструменты: IDA / strings

▸Показать решениенажми, чтобы раскрыть
Ключ: QR-2024-PRO-ACCESS
Строка видна в strings. Защиты фактически нет, патч не нужен.
2

PhotoGlow Proлёгкий

Ключа в открытом виде нет: он в XOR-кодировке, расшифровка в рантайме.

Чему учит

  • Снятие простой XOR-обфускации
  • Чтение цикла расшифровки
  • Патч jz/jnz

Как подойти (2 пути)

  1. Найди массив байт + цикл с xor
  2. A: XOR каждого байта → восстанови строку
  3. B: инвертируй/занопь переход после сравнения

инструменты: IDA · x64dbg · HxD · ключ XOR = 0x5A

▸Показать решениенажми, чтобы раскрыть
Ключ: GLOW-PRO-7F3A-9C2D
XOR-ключ 0x5A. Патч: jnz → jz (или nop) после сравнения.
3

VaultDriveсредний

Keygenme: серийник вычисляется из имени аккаунта. Нужен кейген.

Чему учит

  • Чтение алгоритма целиком
  • djb2-хеш → смешивание → формат
  • Написание кейгена

Как подойти

  1. Найди цикл хеша (умножение на 33)
  2. Проследи xor с константой и sprintf
  3. Повтори формулу → кейген

инструменты: IDA (F5) · любой язык для кейгена

▸Показать решениенажми, чтобы раскрыть
Алгоритм: h=djb2(name); magic=h^0x5A17C0DE;
serial = %04X-%04X-%04X от (magic>>16, magic&FFFF, (h*0x1F+len*7)&FFFF)
Пример: reverser → 7075-2D8D-BD45; neo → 519F-5499-F4AE
Готовый кейген: keygen.exe "имя"
4

SentinelVPNсложный

Анти-отладка + шифрованные строки. Под отладчиком ключ подменяется.

Чему учит

  • Обход IsDebuggerPresent, PEB, NtGlobalFlag
  • Timing-проверки
  • Расшифровка строк в рантайме

Как подойти

  1. Запусти без отладчика — обычный серийник сработает
  2. Под x64dbg: ScyllaHide, обнули BeingDebugged
  3. Пропатчь IsDebuggerPresent → ret 0
  4. Найди константу 0x1337C0DE vs ложную 0xDEADBEEF

инструменты: x64dbg + ScyllaHide · IDA · алгоритм = CRC32(имя)

▸Показать решениенажми, чтобы раскрыть
Без отладчика: k=0x1337C0DE (под отладчиком 0xDEADBEEF — ложный путь)
m=rotl(crc32(name)^k,7); "VPN-%03X-%03X-%02X" от (m>>20&FFF, m>>8&FFF, m&FF)
Пример: reverser → VPN-23E-68A-FE (без отладчика)
Кейген: keygen.exe "имя"
5

PhantomCheat Loaderэксперт

Чит-лоадер: байткод-VM проверяет ключ + анти-тампер + анти-отладка.

Чему учит

  • Девиртуализация VM-протектора (упрощённый VMProtect/Themida)
  • Разбор диспетчера опкодов и таблиц
  • Обход анти-тампера (сумма в seed)

Как подойти

  1. Найди цикл-диспетчер (switch по байтам)
  2. Разбери опкоды: LDK, +таблица, ^keystream, ROL, +prev, STORE
  3. Преобразование обратимо → инвертируй target-блоб
  4. Патч программы VM бесполезен: сумма уходит в seed

инструменты: IDA + F5 · x64dbg · скрипт-инвертор

▸Показать решениенажми, чтобы раскрыть
Ключ: PH4NTOM-VM-2024-UNLOCK
VM на байт: acc=key[i]; +=(0x3B+i*7); ^=KS[i%8]; rol(i%7+1); +=prev; out[i]=acc; prev=acc
Инверсия: t=out[i]-prev; ror(i%7+1); ^=KS[i%8]; -=(0x3B+i*7)
Анти-тампер: seed = SEED ^ (checksum(prog) ^ expected). Запускай без отладчика.
