ReverseLab

Тренажёр по реверс-инжинирингу. Пять самостоятельных crackme-мишеней с нарастающей защитой — от «приложения из тиктока» до защищённого чит-лоадера. Открывай каждый .exe в IDA / x64dbg, разбирай защиту и доставай ключ. Решения ниже спрятаны — открывай, только если застрял.

🎯 5 уровней 🧰 IDA · x64dbg · HxD 🔑 кейгены включены
⚠️ Только для обучения. Все мишени входят в комплект и принадлежат тебе — это и есть смысл crackme. Навыки применяй законно: к собственным сборкам, CTF и авторизованному аудиту, не к чужому коммерческому ПО.
⚙

Подготовка инструментов

Минимальный набор реверсера под Windows x64.

Статический анализ

  • IDA Free/Pro — дизассемблер + декомпилятор (F5)
  • Strings в IDA: Shift+F12
  • Ghidra — бесплатная альтернатива с декомпилятором
  • strings.exe / PE-bear — быстрый осмотр

Динамический анализ

  • x64dbg — отладчик (ставь брейк на сравнение)
  • ScyllaHide — плагин против анти-отладки (L4, L5)
  • HxD — hex-редактор для патчей на диске
  • Запускай мишени в ВМ/песочнице по привычке

Поток работы: strings → найти интересное → xref к проверке → понять логику в декомпиляторе → решить (ввести ключ / написать кейген / пропатчить переход).

1

QuickReels ProNOVICE

«Приложение из тиктока». Ключ лежит открытым текстом и сравнивается напрямую.

Чему учит

  • Поиск строк и перекрёстных ссылок
  • Чтение секции .rdata
  • Базовый статический анализ

Как подойти

  1. Открой ch1_quickreels.exe в IDA
  2. Shift+F12 → ищи строку похожую на лицензию
  3. Двойной клик → x (xref) → к функции сравнения
  4. Ключ прямо там. Введи его.
Инструменты: IDA / strings
Показать решение · нажми
Ключ: QR-2024-PRO-ACCESS
Строка видна в strings дампе — защиты фактически нет. Патч не нужен.
Подсказка без спойлера: strings ch1_quickreels.exe | findstr QR
2

PhotoGlow ProEASY

Ключа в открытом виде нет: он хранится в XOR-кодировке и расшифровывается в буфер перед сравнением.

Чему учит

  • Снятие простой XOR-обфускации
  • Чтение цикла расшифровки
  • Патч условного перехода jz/jnz

Как подойти (2 пути)

  1. Найди массив байт в .data + цикл с xor
  2. A: XOR каждого байта с ключом → восстанови строку
  3. B: найди переход после memcmp и инвертируй/занопь его
Инструменты: IDA · x64dbg · HxD · ключ XOR = 0x5A
Показать решение · нажми
Ключ: GLOW-PRO-7F3A-9C2D
XOR-ключ 0x5A. Патч: jnz → jz (или nop) сразу после сравнения.
Байты в бинаре закодированы; расшифровка — простой однобайтовый XOR.
3

VaultDriveMEDIUM

Keygenme. Ключа нигде нет — серийник вычисляется из имени аккаунта. Нужен кейген.

Чему учит

  • Чтение алгоритма целиком
  • Хеш (djb2) → смешивание → формат
  • Написание кейгена

Как подойти

  1. Найди цикл хеша по имени (умножение на 33)
  2. Проследи xor с константой и финальный sprintf
  3. Повтори формулу в своём коде → кейген
Инструменты: IDA (F5 декомпилятор) · любой язык для кейгена
Показать решение · нажми
Алгоритм: h=djb2(name); magic=h^0x5A17C0DE;
serial="%04X-%04X-%04X" % (magic>>16, magic&0xFFFF, (h*0x1F+len*7)&0xFFFF)
Пример: reverser → 7075-2D8D-BD45; neo → 519F-5499-F4AE
Готовый кейген: tools/keygen (или dist/keygen "имя").
Серийник регистронезависим. Магия в константе 0x5A17C0DE.
4

SentinelVPNHARD

Анти-отладка + шифрованные строки. Под отладчиком в ключ подмешивается другая константа — верный серийник отклоняется, пока не снимешь анти-отладку.

Чему учит

  • Обход IsDebuggerPresent, PEB.BeingDebugged, NtGlobalFlag
  • Timing-проверки
  • Расшифровка строк в рантайме

Как подойти

  1. Запусти без отладчика — обычный серийник сработает
  2. Под x64dbg поставь ScyllaHide, обнули BeingDebugged
  3. Пропатчь IsDebuggerPresent → ret 0
  4. Найди «настоящую» константу 0x1337C0DE vs ложную 0xDEADBEEF
Инструменты: x64dbg + ScyllaHide · IDA · алгоритм — CRC32(имя)
Показать решение · нажми
Константа без отладчика: k=0x1337C0DE (под отладчиком 0xDEADBEEF — ложный путь)
m=rotl(crc32(name)^k,7); serial="VPN-%03X-%03X-%02X"%(m>>20&0xFFF, m>>8&0xFFF, m&0xFF)
Пример: reverser → VPN-23E-68A-FE (без отладчика)
Кейген тот же: dist/keygen "имя".
Если серийник «не тот» под отладчиком — ты поймал анти-отладку. Снимай её.
5

PhantomCheat LoaderEXPERT

Чит-лоадер с максимальной защитой: байткод-виртуальная машина проверяет ключ, плюс анти-тампер и анти-отладка. Прямого сравнения нет.

Чему учит

  • Девиртуализация VM-протектора (упрощённый VMProtect/Themida)
  • Разбор диспетчера опкодов и таблиц
  • Обход анти-тампера (контрольная сумма в seed)

Как подойти

  1. Найди цикл-диспетчер (switch по байтам программы)
  2. Разбери опкоды: LDK, +таблица, ^keystream, ROL, +prev, STORE
  3. Преобразование обратимо → инвертируй target-блоб = ключ
  4. Патчить программу VM бесполезно: сумма уходит в seed
Инструменты: IDA + F5 · x64dbg (трассировка VM) · скрипт-инвертор
Показать решение · нажми
Ключ: PH4NTOM-VM-2024-UNLOCK
VM на байт: acc=key[i]; acc+=(0x3B+i*7); acc^=KS[i%8]; acc=rol(acc,i%7+1); acc+=prev; out[i]=acc; prev=acc
Инверсия (кейген): t=out[i]-prev; t=ror(t,i%7+1); t^=KS[i%8]; t-=(0x3B+i*7); key[i]=t
Анти-тампер: seed = SEED ^ (checksum(prog) ^ expected) — патч программы → мусор на выходе.
Запускай без отладчика (иначе «INTEGRITY CHECK FAILED»). Инвертор — в src/relab_logic.h : l5_invert.
