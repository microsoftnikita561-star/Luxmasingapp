# ReverseLab — тренажёр по реверс-инжинирингу

Набор из **5 учебных crackme-мишеней** под Windows x64 с нарастающей защитой —
от «приложения из тиктока» до защищённого чит-лоадера. Красивый интерфейс в стиле
«жидкое стекло» (Win32 + GDI+). Цель: тренироваться крякать ключи/серийники и
разбирать защиту в **IDA / Ghidra / x64dbg** на бинарниках, которые принадлежат тебе.

> ⚠️ **Только для обучения.** Все мишени входят в комплект — это и есть смысл crackme.
> Применяй навыки законно: к своим сборкам, CTF и авторизованному аудиту, не к чужому ПО.

## Что внутри (`dist/`)

| Файл | Что это |
|------|---------|
| `launcher.exe` | Главное окно: список уровней, прогресс, запуск, кнопка Guide |
| `ch1_quickreels.exe` | **L1 · NOVICE** — ключ открытым текстом |
| `ch2_photoglow.exe` | **L2 · EASY** — ключ в XOR-кодировке + патч перехода |
| `ch3_vaultdrive.exe` | **L3 · MEDIUM** — keygenme (серийник из имени) |
| `ch4_sentinelvpn.exe` | **L4 · HARD** — анти-отладка + шифрованные строки |
| `ch5_phantomcheat.exe` | **L5 · EXPERT** — байткод-VM + анти-тампер + анти-отладка |
| `GUIDE.html` | Подробный гайд по каждому уровню + решения (под спойлерами) |
| `keygen.exe` | Эталонный кейген: `keygen.exe "имя"` |
| `logic_test.exe` | Самопроверка всей логики ключей (должно быть ALL PASS) |

## Как пользоваться

1. Распакуй папку на Windows, запусти **`launcher.exe`**.
2. Нажми **Launch** на уровне → откроется окно-мишень с полем ключа.
3. Параллельно открой этот же `.exe` в **IDA** (или Ghidra/x64dbg) и разбирай защиту.
4. Нашёл ключ / написал кейген / пропатчил переход → введи ключ в окне. Успех
   отмечается зелёным баннером, а в лаунчере загорается **✔ SOLVED**.
5. Застрял — открой **Guide / Solutions** (или `GUIDE.html`), там пошаговый разбор
   и спрятанные ответы.

## Уровни и чему учат

1. **QuickReels** — Strings-окно, xref, чтение `.rdata`. Защиты почти нет.
2. **PhotoGlow** — снятие XOR-обфускации; патч `jz/jnz` после сравнения.
3. **VaultDrive** — чтение алгоритма (djb2-хеш → смешивание → формат), написание кейгена.
4. **SentinelVPN** — обход `IsDebuggerPresent` / PEB / NtGlobalFlag / timing; поиск
   «настоящей» константы, которую прячет анти-отладка (ScyllaHide в помощь).
5. **PhantomCheat** — девиртуализация VM-протектора (упрощённый VMProtect/Themida):
   разбор диспетчера опкодов и таблиц, обход анти-тампера, инверсия target-блоба.

## Инструменты реверсера

- **IDA Free/Pro** или **Ghidra** — дизассемблер + декомпилятор (F5).
- **x64dbg** (+ плагин **ScyllaHide** для L4/L5) — динамический анализ и патчи.
- **HxD** / **PE-bear** — hex-правки на диске и осмотр PE.

## Сборка из исходников

Кросс-компиляция под Windows выполняется на Linux через **mingw-w64**:

```bash
sudo apt-get install -y gcc-mingw-w64-x86-64 g++-mingw-w64-x86-64
cd retrainer
./build.sh          # собирает dist/ и прогоняет самопроверку логики
```

Структура:

```
retrainer/
├─ src/
│  ├─ glasskit.h         # UI-движок «жидкое стекло» (Win32 + GDI+)
│  ├─ challenge_ui.h     # общий шаблон окна-мишени
│  ├─ relab_logic.h      # ВСЯ логика проверки ключей (портируемая, тестируемая)
│  ├─ antidbg.h          # анти-отладка (L4, L5)
│  ├─ launcher.cpp
│  └─ ch1..ch5_*.cpp     # 5 мишеней
├─ tools/
│  ├─ gen.cpp            # генератор констант + самотест (→ logic_test.exe)
│  └─ keygen.cpp         # эталонный кейген (→ keygen.exe)
├─ build.sh
├─ GUIDE.html
└─ dist/                 # готовые .exe
```

Вся логика ключей лежит в одном портируемом заголовке `relab_logic.h` и проверяется
нативным тестом (`logic_test.exe` / `tools/gen.cpp`) — поэтому все ключи и кейгены
гарантированно корректны.

> Примечание: GUI не рендерился под Linux/wine при сборке (нет X-сервера), но все
> `.exe` — валидные Windows PE32+ и используют стандартный GDI+. Превью интерфейса
> см. в `docs/`.
